Written against the unreleased `main` branch.

The plugin is developed by UAMS Web Services in [UAMS-Web/UAMSWP-ACF-Maskfield](https://github.com/UAMS-Web/UAMSWP-ACF-Maskfield). It is based on [acf-maskfield](https://github.com/aluckyar/acf-maskfield) by Alejandro Lucena Archilla, released under the MIT License; the README's [License](https://github.com/UAMS-Web/UAMSWP-ACF-Maskfield#license) section has the details.

## Reporting a problem

Open an issue at [UAMS-Web/UAMSWP-ACF-Maskfield/issues](https://github.com/UAMS-Web/UAMSWP-ACF-Maskfield/issues). Say what you did, what you expected and what happened, the mask you used, and the WordPress, PHP and ACF versions. Check [Troubleshooting](Troubleshooting.md) first.

## Changing the plugin

Changes go through an issue and a pull request to `main`: see [CONTRIBUTING.md](https://github.com/UAMS-Web/UAMSWP-ACF-Maskfield/blob/main/CONTRIBUTING.md). The README's [Tests](https://github.com/UAMS-Web/UAMSWP-ACF-Maskfield#tests) section says how to run the suite.

## Editing this wiki

These pages live in [`docs/wiki/`](https://github.com/UAMS-Web/UAMSWP-ACF-Maskfield/tree/main/docs/wiki) and are published by the `Publish wiki` workflow when a release is published, or when it is run by hand. Each publish replaces the whole wiki with that folder, so edit the files through a pull request, not in the browser.

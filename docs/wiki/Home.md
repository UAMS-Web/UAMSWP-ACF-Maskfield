UAMSWP ACF Mask Field adds a **Mask Field** type to Advanced Custom Fields: a text input that only accepts what its mask allows, such as a phone number, a ZIP code or an ID with a fixed format. The mask is applied in the editor by the [Inputmask](https://github.com/RobinHerbots/Inputmask) library.

This wiki holds the documentation: a walkthrough, a guide to writing masks, the reference, and troubleshooting. The [README](https://github.com/UAMS-Web/UAMSWP-ACF-Maskfield#readme) keeps an overview, the requirements, installation, tests and the license.
